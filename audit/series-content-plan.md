# План содержания сериалов — 6 ноября 2026

В реестре 49 карточек сериалов и мультсериалов. Только три сезона «Что, если…?» имеют эпизоды: 26 серий, 259 отмеченных участий с непустыми описаниями. Остальные 46 карточек не имеют списка серий. Карточка может содержать несколько сезонов, поэтому 49 — не количество сезонов. Два фильма Spider-Verse ошибочно имеют тип `anim = Мультсериал`; в этот план они не включены.

Машиночитаемая очередь: [series-content-plan.json](series-content-plan.json). Пустой `expectedEpisodes` означает, что число ещё нужно сверить, а не что в сезоне нет серий. Даты и заявленные сезоны в очереди перенесены из текущего гайда; это не новая проверка расписания премьер.

## С чего начинаем

1. Проверить полный список сезонов и эпизодов, отделить вышедшее, выходящее и анонсированное. Сверять с официальными карточками Marvel/Disney+ и титрами. Не писать сюжет невышедших серий.
2. Подготовить общий шаблон серии, затем пилот из девяти серий «ВандаВижн». Их количество подтверждено [официальным указателем Marvel](https://www.marvel.com/tv-shows/wandavision/1?cache=update1).
3. После проверки пилота: оба сезона «Локи», «Агата», затем доступные серии «ВижнКвеста». Для выходящих сезонов обновлять статус каждой серии отдельно.
4. Идти по очереди ниже. Выпускать небольшими партиями: один короткий сезон или 6–10 эпизодов длинного сезона. Для каждой партии — источники, вычитка, проверка спойлеров и ссылок.

## Что хранить о каждой серии

| Поле | Что писать |
| --- | --- |
| Идентификатор | Сериал + номер сезона + номер серии; не индекс строки в массиве |
| Название | Оригинал и русский вариант, с пометкой рабочего перевода при необходимости |
| Дата / статус | Премьера, вышла / анонсирована / проверяется |
| Краткая подводка | 1–2 предложения без развязки |
| Сюжет | Завязка → конфликт → ключевые действия → итог; обычно 5–8 предложений, для короткометражной анимации меньше |
| Значение | Что эта серия меняет для героев и следующих историй; без натянутой связи со всеми «Мстителями» |
| Персонажи | Только реально появившиеся, с различием живого участия, голоса, архива, упоминания и альтернативной версии |
| Действия персонажа | 1–3 конкретных предложения именно о его роли в этой серии |
| Исполнители | По титрам этой серии; не наследовать автоматически актёра основной киноверсии |
| Сцены в титрах | Нет / есть / ещё не проверены; хранить отдельно от финальной сцены до титров |
| Связи | Проекты, события, предметы, материалы, места; проверенные ссылки |
| Источники / редактура | Ссылка, что именно ею подтверждено, дата проверки и готовность |

Подробный сюжет, развязки, секретные личности, состав с неожиданными появлениями и сцены в титрах должны подчиняться режиму спойлеров. «Персонаж есть в базе» не означает, что полный состав уже проверен.

## Что сначала изменить в устройстве эпизодов

- Убрать обязательную приставку «Что, если» из `episodeList`, `episodeView`, `epNotes`.
- Перестать называть все эпизодические появления «другими версиями в других реальностях»: это неверно для «ВандаВижн» и обычных сериалов.
- Ввести номер сезона у серий объединённых карточек: «Агенты Щ.И.Т.а» (предварительно 7), «Агент Картер» (2), «Беглецы» (3), «Плащ и Кинжал» (2), «Легион» (3), «Одарённые» (2), «Я есть Грут» (2). Эти числа нужно сверить при инвентаризации.
- Сохранить существующие 26 адресов «Что, если…?» через совместимые маршруты. Переносить редактируемые тексты по постоянному ID, чтобы добавление серии не сдвигало чужие правки.
- Сделать единственный реестр участия персонажа в серии, из которого выводятся обе стороны связи. Переиспользовать уже имеющийся реестр `appearances` для итогов сезона.
- Добавить проверку: уникальность номера внутри сезона, отсутствие чужих ID, обоснованность статуса «проверено», непустой опубликованный сюжет.

## Когда партия готова

У каждой опубликованной серии есть проверенные номер и название, собственный сюжет, конкретные действия основных героев, проверенный статус сцен в титрах и рабочие связи. Общий пересказ сезона не копируется в каждую серию. Непроверенный камео не получает статус подтверждённого. В режиме скрытых спойлеров неожиданный состав и развязка не видны. Сохранённые правки и старые ссылки не теряются после миграции.
