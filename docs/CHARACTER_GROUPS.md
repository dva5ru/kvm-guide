# Группы персонажей

Категории на странице героев — независимые фильтры. У персонажа может быть несколько групп. Для официальных команд указываем фактическое членство, для окружения — сюжетную связь, для локаций — значимую связь с местом или историей.

**Не создаём группы на одного-трёх участников.** Вместо отдельных семей, «друзей» и разовых персонажей используем устойчивые сюжетные окружения. Исключение допускается только при отдельно обоснованном расширении каталога (в текущем наборе исключений нет).

Не переносим составы из комиксов в экранизации без проверки. Различаем сотрудника организации, временного союзника и противника. Не удаляем карточки и связанные появления при изменении категорий.

В данных: 702 персонажа, 50 групп, 0 групп меньше четырёх. Поле `g` должно быть равно `groups[0]`. После редактирования `data/characters.json` обязательно запускать `npm run stamp`, `npm run validate` и `npm test`.

**Важно:** админские переопределения категорий в `content.json` могут сохранять старые названия поверх основной базы. Не очищать файл автоматически: он содержит другие пользовательские изменения и фотографии. Проверять старые переопределения отдельно.
