# Сквозная редакторская модель: даты, появления, переиздания и анонсы

## Даты
У каждого проекта поле `r` остаётся датой премьеры для каталога и сортировки; `y` — **год выхода**, не календарный год действия. Новый `release` явно задаёт дату/точность, а `periods` хранит отдельные интервалы действия, флешбэки, путешествия во времени, эпилоги, рамки других вселенных. У неизвестного периода — пустой список, а не придуманный год. В карточке периоды выводятся по отдельным строкам.

Разметка ключевых случаев: `cap1`, `captain-marvel`, `eternals`, `endgame`, `loki-1`, `loki-2`, `dofp`, проекты What If?, Spider-Verse, X-Men ’97 и Endeame Encore. Существующие годы `w` остаются для совместимости со списками.

## Появления
В `appearances` независимо хранятся `role` (старый код для обратной совместимости), `appearanceType` (main/episodic/cameo/voice/archival/credits), `delivery` (on-screen/voice/archival) и `placement` (main/credits/main-and-credits). Это позволяет, например, пометить голос из сцены в титрах без выдачи его за живое появление.

`versionId` — ссылка на конкретную карточку персонажа. Для прежнего `role:X` дополнительно сохраняются `versionRef`, `versionScope` и `versionLabel`. В многосерийной анимации `versionRef` включает ID серии, чтобы разные миры не сливались в одного героя. Для известных перенесённых героев могут указываться `originProjectId` (например, Джонни из «Фантастической четвёрки»). Там, где исходный мир не подтверждён, не придумывается номер Земли.

## «Что важно для КВМ»
В читательском режиме показывается краткое редакторское резюме `imp`; при его отсутствии — отдельные ключевые факты `key`. Вместе они больше не дублируются. Админка по-прежнему может редактировать оба существующих набора. Для содержательной вычитки фактов по каждому проекту необходим отдельный редакторский проход.

## Переиздания
`endgame-encore` и `once-upon-a-deadpool` открываются в отдельном представлении различий: новые кадры/сцены, только новые участники относительно оригинала и ссылка на полную исходную карточку. Сведения о предметах, сюжет, основной состав и важные события исходной версии не повторяются. Список канонических появлений и существующие alias/override ключи не удалены, чтобы сохранить историю правок.

## Будущие фильмы
Страница ещё не вышедшего фильма использует лишь `announcement.summary` и официальные ссылки; пересказ `sto`, блок «Что важно» и вымышленные события не показываются. Подтверждённые персонажи из `appearances` обозначаются как **объявленные**, а не уже появившиеся. Для других будущих проектов без источников выводится нейтральное сообщение об отсутствии официального описания.

Источники: Disney Movies / Disney D23 2026 / Disney Comic-Con 2026 / Disney+ (URL хранятся в `announcement.sources` соответствующих проектов).

Важно: эта работа обеспечивает сквозную структуру и базовую фактологию. Она не заменяет покадровую проверку всех 1320 появлений и не утверждает, что все 156 аннотаций полностью проверены редактором.
